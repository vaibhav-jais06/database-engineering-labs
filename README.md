## 🚀 Getting Started

To explore these labs locally on your machine, follow these steps:

### Prerequisites
Make sure you have [Python 3.x](https://www.python.org/) and [Git](https://git-scm.com/) installed.

### Installation

1. **Clone the repository**
   ```sh
   git clone https://github.com/vaibhav-jais06/database-engineering-labs.git
   ```
2. **Navigate to the project directory**
   ```sh
   cd database-engineering-labs
   ```
3. **Install the required libraries**
   ```sh
   pip install pandas jupyter
   ```
4. **Fire up Jupyter Notebook**
   ```sh
   jupyter notebook
   ```
