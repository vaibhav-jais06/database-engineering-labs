## 💡 What's Inside?

This repo focuses on practical applications of database concepts, including:
- **Relational Data Modeling:** Understanding entities (e.g., Teams, Players) and their relationships.
- **Data Querying & Filtering:** Extracting specific subsets of data based on constraints (e.g., finding young players, filtering by roles).
- **Data Transformation:** Structuring raw data into readable and analyzable formats.

## 🚀 How to Run Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/vaibhav-jais06/database-engineering-labs.git
   ```
2. **Navigate to the directory:**
   ```bash
   cd database-engineering-labs
   ```
3. **Install dependencies (if not using Google Colab):**
   ```bash
   pip install pandas jupyter
   ```
4. **Launch Jupyter:**
   ```bash
   jupyter notebook
   ```
