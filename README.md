## 📖 About This Repository

> *"Data is the new oil. It’s valuable, but if unrefined it cannot really be used."*

This repository is my digital workbench for **Database Management Systems** and **Data Engineering**. It serves as an evolving portfolio documenting my transition from foundational data structures in Python to complex, enterprise-level RDBMS operations.

<details>
<summary><b>🔥 Core Objectives</b></summary>
<br>

* **Master Relational Modeling:** Design bulletproof schemas using Primary, Foreign, and Composite Keys.
* **Write Performant Queries:** Go beyond basic `SELECT` statements into CTEs, Window Functions, and advanced joins.
* **Database Normalization:** Master 1NF through BCNF to ensure data integrity and eliminate redundancy.
* **Bridge Python and SQL:** Use Pandas as an analytical stepping stone to raw SQL execution.
</details>

## 🚀 Getting Started

Want to run these notebooks locally? Follow these simple steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/vaibhav-jais06/database-engineering-labs.git
   ```
2. **Navigate into the project:**
   ```bash
   cd database-engineering-labs
   ```
3. **Install Dependencies:**
   ```bash
   pip install pandas jupyter
   ```
4. **Launch the environment:**
   ```bash
   jupyter notebook
   ```
